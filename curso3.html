Backend con Node.js

Domina el desarrollo backend con Node.js, Express, bases de datos y despliegue de aplicaciones.

⚙️ Programa del Bootcamp: Backend con Node.js (10 Semanas)

Ruta intensiva para construir APIs seguras y escalables con Node.js y Express.

Módulo 1: Fundamentos de Node.js (Semanas 1-2)

−
  • **Semana 1:** JavaScript Avanzado, Asincronía, Promesas y `async/await`.
  • **Semana 2:** Node.js Core, Módulos Nativos, NPM y El Event Loop.

Módulo 2: Desarrollo de APIs con Express (Semanas 3-5)

+
  • **Semana 3:** Introducción a Express.js, Middleware y Routing.
  • **Semana 4:** Diseño de API RESTful, Códigos de Estado y Manejo de Errores.
  • **Semana 5:** Lógica de Negocio, Consumo de APIs Externas y Websockets.

Módulo 3: Persistencia de Datos (Semanas 6-7)

+
  • **Semana 6:** Bases de Datos SQL (PostgreSQL/MySQL), ORMs (Sequelize) y Migraciones.
  • **Semana 7:** Bases de Datos NoSQL (MongoDB), Mongoose y Optimización de Consultas.

Módulo 4: Seguridad, Testing y Despliegue (Semanas 8-10)

+
  • **Semana 8:** Seguridad Web, Validación de Datos (Joi/Zod) y Hashing con `bcrypt`.
  • **Semana 9:** Autenticación con JSON Web Tokens (JWT) y Autorización.
  • **Semana 10:** Testing (Jest/Supertest), Docker y Despliegue a Producción.
¡Conviértete en un Experto Backend con Node.js!
