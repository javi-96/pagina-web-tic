Desarrollo Web Full-Stack

Aprende HTML, CSS, JavaScript, React, Node.js y bases de datos para convertirte en desarrollador full-stack.

Programa del Bootcamp (16 Semanas)

Una ruta intensiva para dominar el Front-End y el Back-End.

Módulo 1: Fundamentos de la Web y Maquetación (Semanas 1-4)

−
  • **Semana 1:** HTML5, Semántica y Accesibilidad Básica.
  • **Semana 2:** CSS3, Modelos de Caja y Estilos.
  • **Semana 3:** CSS Avanzado, Flexbox, Grid y Responsive Design.
  • **Semana 4:** Introducción a JavaScript (Básico: Tipos de Datos, Funciones, DOM).

Módulo 2: Desarrollo Front-End con React (Semanas 5-8)

+
  • **Semana 5:** JavaScript Moderno (ES6+): Promesas y Async/Await.
  • **Semana 6:** Fundamentos de React, Componentes, JSX, Props y State.
  • **Semana 7:** React Hooks Esenciales (`useState`, `useEffect`) y Fetching de Datos.
  • **Semana 8:** React Router, Gestión de Estado Global (Context API) y Estilización.

Módulo 3: Desarrollo Back-End con Node.js y Bases de Datos (Semanas 9-12)

+
  • **Semana 9:** Node.js y Express.js, Creación del Primer Servidor y Rutas.
  • **Semana 10:** Bases de Datos SQL, Consultas Básicas y Relaciones (PostgreSQL/MySQL).
  • **Semana 11:** Bases de Datos NoSQL (MongoDB), Mongoose y API RESTful.
  • **Semana 12:** Seguridad, Implementación de Autenticación con JWT y Hashing de Contraseñas.

Módulo 4: Proyecto Final, Despliegue y Profesionalización (Semanas 13-16)

+
  • **Semana 13:** Testing, Buenas Prácticas y Control de Versiones Avanzado (Git).
  • **Semana 14:** Despliegue de Aplicaciones Full-Stack (Vercel/Netlify y Render/Heroku).
  • **Semana 15:** Desarrollo y Revisión del Proyecto Final Integrador.
  • **Semana 16:** Presentación de Proyectos, Portafolio y Preparación para Entrevistas Técnicas.
