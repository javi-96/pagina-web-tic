Frontend con React

Especialízate en desarrollo frontend moderno con React, Redux y las últimas herramientas del ecosistema.

Programa del Bootcamp: Frontend con React (12 Semanas)

Una ruta intensiva para dominar el Front-End y convertirse en un especialista de React.

Módulo 1: Fundamentos Acelerados y JavaScript Moderno (Semanas 1-4)

−
  • **Semana 1:** HTML5, CSS Avanzado, Flexbox, Grid y SASS (Revisión).
  • **Semana 2:** JavaScript Core: Tipos de datos, Funciones y Estructuras de control.
  • **Semana 3:** JavaScript Moderno (ES6+): Asincronía, Promesas y Async/Await.
  • **Semana 4:** POO, Módulos, Manipulación Avanzada del DOM y NPM.

Módulo 2: Dominio de React Core (Semanas 5-8)

+
  • **Semana 5:** Fundamentos de React, Componentes Funcionales y JSX.
  • **Semana 6:** Estado (`useState`), Eventos y el Hook `useEffect`.
  • **Semana 7:** Manejo de Formularios (Librerías), Fetching de Datos con Axios.
  • **Semana 8:** React Router DOM, Composición Avanzada y Custom Hooks.

Módulo 3: Estado Global, Testing y Ecosistema (Semanas 9-12)

+
  • **Semana 9:** Gestión de Estado Global con **Redux Toolkit (RTK)** y Hooks de Redux.
  • **Semana 10:** Estilización Avanzada (Styled Components/Tailwind), UI/UX y Accesibilidad.
  • **Semana 11:** Testing de Componentes con **Jest** y **React Testing Library**.
  • **Semana 12:** Despliegue (Vercel/Netlify), Optimización, Proyecto Final y Portafolio.
¡Comienza tu Especialización en React Hoy!
